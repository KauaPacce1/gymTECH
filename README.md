# 💪 gymTECH

## 📖 Sobre o projeto

O **gymTECH** é uma aplicação web para praticantes de musculação que permite registrar treinos e acompanhar a própria evolução por meio de dashboards. O sistema mostra a frequência mensal e o volume semanal de séries por grupo muscular, comparado à faixa recomendada, e conta ainda com uma área informativa sobre exercícios.

Projeto individual desenvolvido por mim, estudante de Análise e Desenvolvimento de Sistemas na SPTECH.

## ✨ Funcionalidades

| Recurso | Descrição |
| --- | --- |
| 📝 **Registro de treinos** | Cadastre os dias frequentados, os exercícios realizados e o número de séries de cada um. |
| 📅 **Dashboard de frequência mensal** | Veja em quais dias do mês você treinou e acompanhe sua consistência. |
| 📊 **Dashboard de volume semanal** | Compare as séries semanais por grupo muscular com a faixa recomendada e descubra o que está abaixo, dentro ou acima do ideal. |
| 📚 **Área informativa** | Consulte detalhes sobre os exercícios: grupo muscular trabalhado, execução e mais. |

## 🛠️ Tecnologias

- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** Node.js
- **Banco de dados:** MySQL
- **Gráficos:** Chart.js
